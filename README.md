# AWS CloudFormation - Automatically launched EC2 instance 

## Project Overview

This project demonstrates how to use AWS CloudFormation to automatically 
create an EC2 instance using Infrastructure as Code (IaC).

## AWS Services Used

* AWS CloudFormation
* Amazon EC2
* Amazon VPC
* Security Group
* Amazon Linux

## Objective

* Automate EC2 instance creation.
* Avoid manual configuration.
* Create repeatable infrastructure.

## Prerequisites
* CloudFormation Template (YAML/JSON)
* Existing Key Pair
* Existing VPC and Subnet

## Outcome

* EC2 instance launched automatically.
* Infrastructure created in a few minutes.
* Entire infrastructure managed using code.

## Benefits

* Infrastructure as Code (IaC)
* Automation
* Faster deployment
* Consistent configuration
* Easy to recreate infrastructure

## Real-World Use Case

Companies use CloudFormation to automatically deploy servers,applications,
and complete environments for development, testing, and production.

## Skills Demonstrated

* AWS CloudFormation
* EC2
* Infrastructure as Code
* AWS Networking Basics
* Cloud Automation
